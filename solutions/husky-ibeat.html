What is protected

CO uses a single Apply click, with no prepare/confirm sequence. The app reads the previous word first and keeps an audit entry before sending the write.

TPS reset checks RPM twice and checks that the sampled voltage has not moved. A final confirmation is retained for this calibration operation.

A missing acknowledgement never triggers another write automatically. A readback attempt is made after a drain interval, and any uncertain result stays marked as uncertain.

Changes persist in the ECU. Closing this page does not roll them back. Restore original is an explicit, verified write to the current session's baseline.

Release scope

This is an independent diagnostic test release for the project's Mikuni EFI command set, not a Mikuni or Husqvarna product. It is not a firmware flasher. Feedback-setting writes, long-term adaptation reset, VIN/engine-number editing and iBeat's service-history database are not implemented.

Nothing displayed in Demo mode is a reading from your bike. Reconnecting or switching between Demo and USB clears cached values and session calibration originals.

Connection settings

Settings apply on the next connection. Baud rate is fixed at 19,200; 8 data bits, no parity, 1 stop bit, no hardware flow control. Every ECU command is terminated by CR+LF. No ISO slow initialization or password is sent.

First connection & troubleshooting

Use a direct serial USB-to-K-line adapter with the correct motorcycle connector/pinout, such as your working iBeat cable. An ELM327 command interpreter is not a transparent substitute. The bike supplies K-line power; USB power alone may only power the adapter.

Open this HTML file as its own page in desktop Chrome or Edge, not inside an attachment preview. The adapter must be available as a serial port to the operating system. Close iBeat, Arduino Serial Monitor and terminal apps before connecting.

Echo with no payload means the adapter heard your command, not that the ECU answered. Check the key/kill-switch state, adapter power, K-line connection and ground. A red status after a timeout stops polling; use Resynchronize or disconnect/reconnect after fixing the cause.

This release targets a laptop/desktop browser. Feature detection, not a guessed browser name, controls Connect USB. For a browser that blocks local-file access, serve the included file on localhost using start_local.py. There is no cloud service and no network traffic.

Conversions & implementation notes
ParameterCommandFormulaEvidence / status

The older Rev1.1 document contains conflicting RPM formulas and reversed spark/injector labels. This build uses the later project mapping instead: RPM raw × 500 / 256, spark at 07, injection at 08, temperatures raw / 256 − 50. Read docs/PROTOCOL.md in the complete package for provenance and exclusions.

Engine hours = (upper word × 65536 + lower word) / 6. CO = raw × 100 / 4096. New CO words are rounded to the nearest integer. The app does not use JavaScript's signed 32-bit arithmetic for the combined hours value.

The protocol has no request identifier or checksum in the observed replies. This implementation uses one request at a time, strict response validation, bounded buffers, a quiet interval and a timeout quarantine. Extremely late replies cannot be perfectly identified by software alone.
